Run logs under `artifacts/` and external project `Saved/` directories are not
tracked in this repository. A historical path is a locator for retained evidence,
not a file promised by a fresh clone. Reproduction requires the documented
toolchain, fixtures and original verification scope. Report missing evidence
honestly; do not substitute a new lightweight check for an old native verdict.
